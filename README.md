# El Estudio Tattoo — propuesta web

Landing editorial creada en Next.js para El Estudio Tattoo, Barcelona.

## Desarrollo

```bash
npm install
npm run dev
```

## Verificación

```bash
npm run lint
npm run build
node --test tests/rendered-html.test.mjs
```

Las fotografías incluidas proceden de publicaciones públicas del negocio y sus artistas. Antes de la entrega definitiva debe confirmarse su uso con el estudio.
